# 标书生成 · 完整操作指引

> 适用版本：预发布 2026-10-25 起（`c94f361` 及之后）。产品入口：Word 中「标捷通」插件 → 标书生成。
> 本工具当前仅编写**技术标书**；商务标内容（报价、资质证明等）不在生成范围内，由投标人线下准备。

## 0. 前提条件

1. 已安装标捷通插件并用账号登录（插件菜单在 WPS / MS Word 的「标捷通」组）。
2. 在 Word 中打开（或新建）投标文件文档，点开「标书生成」进入本页面。
3. 页面顶部显示与 Word 文档的连接状态；点数余额显示在右上角——AI 解析、撰写、审读按用量消耗点数。

## 1. 四步主流程

### 步骤一 · 素材准备

- **招标文件（必填）**：可上传多份（doc/docx/pdf 等）；系统自动解析出评分办法、工期、★条款等招标要素。
- **公司素材（建议尽量全）**：资质业绩、方案资料、人员证书、历史标书/模板等。系统自动建立素材索引，撰写时只引用真实素材、不虚构。
- 历史标书会被识别为「历史模板」，生成大纲时参照其目录结构（只参照层级与覆盖面，不照抄章节名）。
- 上传后等待索引完成再进入下一步（页面有索引状态提示）。

### 步骤二 · 需求确认

按推荐顺序处理四张卡片（页面已标注 ①②③④）：

1. **① 生成要求**（字数必填）：目标总字数、是否配图；配图可选标准/新版渲染引擎（新版对架构、流程、甘特、时序图更精美）。
2. **② 素材检查和需求确认**：点「开始检查」后 AI 对照招标要求检查素材，就缺口向你提问——逐条作答（建议答案可直接采纳，也可改为实际情况）；补充新素材后点「再次检查」让 AI 复查。
3. **③ 应答口径**：逐条确认关键口径（如本地算力优先还是在线、数据是否出内网等），生成全稿按此统一。
4. **④ 额外的需求**（可选）：其他编写要求（如必须包含的章节、指定表述方式）。

### 步骤三 · 编写大纲

- AI 生成目录、每章摘要与图表规划（每章规划哪些表、哪些图）。
- 可**拖拽排序**章节、**编辑**标题/摘要/篇幅/图表计划，或用一句话让「**AI 修改**」调整。
- 点「**下一步：逐章撰写（确认大纲）**」时系统做两项检查：
  - **评分项覆盖硬门禁**：技术类评分项（如「技术规范书应答 12 分」）必须有章节响应，有漏项会提示——点「AI 修改」下达补章指令或手动添加章节，补齐后才能确认；
  - 字数区间核对（大纲规划合计须落在目标 ±20%）。

### 步骤四 · 逐章撰写

1. 选择**写入模式**：
   - **审读后统一写入（推荐）**：全文生成 → AI 审读优化 → 再统一写入 Word；
   - 边写边出：每章生成完自动写入；
   - 逐章确认：每章预览后手动写入。
2. 点「开始撰写」**之前**，先在 Word 中点击要开始插入的位置（系统在该处建立锚点）。
3. 撰写在云端进行，**可离开页面**；重新进入自动恢复进度。生成完成后系统自动做全稿机检并**自动修复不合格项**（图表编号重号、图表内占位、失效引用、禁用词等），复检合格才出质检报告。

## 2. 成稿后动作（推荐顺序）

| 顺序 | 动作 | 说明 |
|---|---|---|
| ① | **AI 审读优化全稿** | AI 通读全文，找出影响得分的问题（口径矛盾、内容缺失、与招标要求不符等）并自动修订重点章节。消耗点数，提交前先出预估确认。一轮封顶。 |
| ② | 查看**全稿质检报告** | 只呈现复检后的合格状态；系统自动修复的项会标注「已自动修复 N 处 / 已重排图表编号 N 处 / 已压缩超稿章节 N 章」。 |
| ③ | **写入 Word**（N 章待写入） | 全部章节统一写入当前 Word 文档，不调用 AI、不计费。已写入后按钮变「重新写入 Word」。 |
| ④ | **复制全稿文本** | 复制全部已生成章节的 Markdown 源文本（含表格与图示源码），可粘贴到任意编辑器继续加工。 |
| — | **移除全部 AI 内容**（红色，右侧） | 从当前 Word 文档删除全部 AI 撰写章节及其中的手工修改（**一次 Ctrl+Z 可整体恢复**）；移除后可在目标位置「重新写入 Word」，也可换新文档重写整本。 |

## 3. 单章操作

- **重生成**：对不满意的章节单独重写（AI 重新生成本章）。
- **替换 Word 中本章**：重生成/修订后的章节写回 Word 时替换旧章（会覆盖本章内的人工修改；每章写入后可用一次 Ctrl+Z 撤销该章）。
- **移除本章**：仅移除单章。

## 4. 计费与点数

- 消耗点数的环节：素材解析索引、需求检查、大纲生成、逐章撰写（按生成字数）、AI 审读优化；机检自动修复随撰写/审读任务结算，不额外计费。
- 写入 Word、复制全稿、移除、重新写入**均不计费**。
- 各环节提交前有预估确认；点数余额见页面右上角。

## 5. 常见问题

| 现象 | 处理 |
|---|---|
| 页面显示与 Word 断开 | 点「重新连接文档」；仍不行则关闭页面重新从插件进入 |
| 确认大纲被拦下（提示评分项未响应） | 按提示点「AI 修改」补章（如「为技术规范书逐条应答增设专门章节」）或手动添加章节后重试 |
| 想把已写入内容挪到别的位置 | 「移除全部 AI 内容」→ 在目标位置「重新写入 Word」 |
| 生成中误关页面 | 无需处理，重进自动恢复；云端任务继续执行 |
| 某章内容不满意 | 章节上点「重生成」→「替换 Word 中本章」 |
| 商务标/报价内容 | 本工具不生成，请线下编制（评分覆盖卡中商务类项标注「商务人工准备」） |
| 页面样式或按钮异常（旧版） | 浏览器强制刷新一次（Ctrl+F5）——插件内嵌页可能缓存旧脚本 |
