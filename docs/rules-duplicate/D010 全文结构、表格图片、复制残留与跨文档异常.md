# D010 全文结构、表格图片、复制残留与跨文档异常

## 检查目标

从全文层面检查章节结构、连续段落、表格、图片/OCR、复制残留和跨文档证据簇，弥补单一业务规则无法覆盖的模板级与版面级异常。结果只用于人工复核，不作串标、围标或其他法律定性。

## 适用证据与检索通道

- 以标题、段落、目录、页眉页脚可提取文本、表格/表格行、图片哈希、OCR、图注和相邻上下文为证据。
- lexical 发现连续复制和残留文本；structure 比对章节/编号/表格；semantic 发现章节移动与改写；image 比对图片哈希、感知哈希和 OCR。
- 本规则用于跨域兜底和聚类，不应重复输出已由 D001-D009 给出且证据完全相同的结果。

## 检查项

### 检查项1：目录、标题和章节编号

- 比对目录层级、标题顺序、编号格式、跳号、重复编号和正文引用关系。
- 公共章节模板不充分；相同非标准标题、相同跳号和相同缺章同时出现时提高证据。

### 检查项2：连续段落、章节移动和改写

- 检查连续两段以上的近似文字、跨章节移动、句序调整和同义替换。
- 聚合同一连续片段，记录起止位置和出现次数，避免逐段重复计数或左右镜像重复。

### 检查项3：表格结构和数值指纹

- 比对表头、行列、空值、排序、稀有单元格、数字组合和隐藏备注。
- 只有公共表头不充分；表格结构、罕见单元格、异常单位和正文映射同时一致时重点复核。

### 检查项4：图片、图表、截图和 OCR

- 比对图片 SHA-256、感知哈希、尺寸、裁剪、图注、页码和 OCR 文本。
- 同一证书模板或公共图标可合理重复；相同裁剪、内部截图、异常 OCR 和正文引用构成组合证据。

### 检查项5：公司、项目、联系人和路径复制残留

- 检查另一方公司名、项目名、人员、电话、邮箱、域名、内部系统、文件路径、版本和账号痕迹。
- 残留文本即使相似度不高，也可用 logic_anomaly 标记，但必须引用双方真实原文或上下文。

### 检查项6：错别字、标点、编号和格式异常

- 比对罕见错字、同一病句、异常标点、单位拼写、段落跳号和未闭合占位符。
- 常见输入错误不充分；错误与长文本、数字、表格或图片同时一致时提升证据强度。

### 检查项7：跨文档证据簇和多方传播

- 识别同一独特片段、图片、表格行或残留在多个文档对中的传播，保留文档 ID 和所有 occurrence。
- 同一证据簇只生成一个主结论，说明涉及文档范围；不得把多次出现简单等同于法律事实。

### 检查项8：模板、短语和重复噪声降权

- 识别页眉口号、固定声明、目录词、短标题及同一文档反复出现的模板语句。
- 对短文本、高出现次数和低证据强度候选降权，避免其挤占长而独特的异常内容。

## 合理重复

- 招标文件模板、公共目录结构、法规/标准原文、厂家公共图片和通用页眉页脚。
- 短标题、常见声明、公共图标、标准表头及同一文档内高频模板语句。
- 有完整 tender/public 来源且 A/B 仅复用来源部分的候选标记 reasonable。

## 疑似不合理重复

- 长而独特的连续章节、相同移动顺序、相同异常标题和复制残留共同出现。
- 表格稀有单元格、图片哈希/OCR、公司或路径残留在多个文档间形成闭环。
- 跨文档出现相同非公开内部系统、联系人、版本、账号或未替换占位符。

## 排除与降级

- 短文本、高频模板、公共图片、低证据结构相似和已被其他规则完整覆盖的同一候选不重复输出。
- 文档解析覆盖不足、图片未哈希/OCR、表格未结构化、来源快照缺失或上下文不完整时标记 unknown。
- 证据不足时不得推断传播路径、文件作者、协同行为或违法；不得作出确定性的违法结论。

## 输出要求

- 引用双方文档 ID、原文/表格/图片位置、上下文、所有 occurrence、通道分数、相似度和证据强度。
- 对跨文档簇说明主证据、关联证据和去重/聚合方式；对解析不足明确列出缺口和人工检查项。
- verdict 只能为 reasonable、suspicious 或 unknown；不得作出确定性的违法结论。
