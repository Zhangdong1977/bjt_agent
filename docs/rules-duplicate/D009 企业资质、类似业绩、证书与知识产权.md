# D009 企业资质、类似业绩、证书与知识产权

## 检查目标

检查企业资质、类似业绩、合同案例、证书、荣誉、专利和软件著作权等材料的文本、编号、图片及逻辑一致性，识别跨公司复制和异常附件。结果仅用于人工复核，不作资质造假、串标、围标或其他法律定性。

## 适用证据与检索通道

- 以资格响应表、资质证书、业绩表、合同关键页、验收证明、荣誉证书、专利和软件著作权附件为证据。
- lexical 比对客户、金额、日期、编号和业绩叙述；structure 比对证书/业绩表；semantic 比对改写后的项目案例；image 检查印章、证书图片、截图和 OCR。
- 公开登记信息或厂商公共资料只有在固化来源、版本和位置完整时，才能解释合理重复。

## 检查项

### 检查项1：企业资质和许可清单

- 比对资质名称、等级、证书号、发证机关、有效期、许可范围和表格顺序。
- 标准资质名称可合理重复；跨公司出现同一证书号、有效期错误或另一方名称残留时应重点复核。

### 检查项2：类似业绩项目叙述

- 比对项目背景、客户、规模、合同范围、实施难点、成果和验收结论。
- 只替换客户名但保留同一罕见数字、技术难点、成果指标和错字，标记为疑似不合理重复。

### 检查项3：合同金额、日期和联系人逻辑

- 比对合同金额、签订/验收日期、项目周期、联系人、电话尾号和合同编号。
- 关注金额与规模不一致、日期倒置、联系人跨公司复用及相同遮盖/脱敏位置。

### 检查项4：认证证书、荣誉和奖项

- 比对体系认证、检测报告、荣誉奖项、证书编号、图片排版和说明文字。
- 相同的过期日期、拼写错误、OCR 误识别或不属于本公司的证书名称属于增强证据。

### 检查项5：专利、软件著作权和产品证明

- 比对专利号、软著登记号、产品名称、版本、权利人、取得日期和与本项目的关联说明。
- 公共登记字段可重复；相同内部产品别名、错误登记号、关联说明和附件顺序应重点复核。

### 检查项6：财务、信用与履约证明

- 比对审计年度、关键指标、信用等级、承诺编号、无重大违法声明和履约评价。
- 招标模板可合理重复；未要求的解释段落、相同异常数字或另一方机构名称残留可形成疑似证据。

### 检查项7：附件图片、印章和 OCR 异常

- 检查证书/合同图片哈希、裁剪区域、印章位置、遮盖方式、页码、OCR 文本和文件名。
- 图片相似必须与编号、权利人或正文映射结合；仅使用同一公共证书模板不足以判定。

## 合理重复

- 招标文件明确要求的资格响应字段、标准资质/认证名称和公共登记信息。
- 同一厂家公共产品证书、公开专利/软著字段及政府平台固定格式；须提供 public 来源。
- “具有类似项目经验”等通用表述及单个年份、金额单位不单独判定。

## 疑似不合理重复

- 跨公司出现同一证书/登记号、合同编号、联系人尾号、异常日期或附件遮盖方式。
- 姓名/客户名被替换但完整业绩难点、成果数字、错误和说明顺序仍一致。
- 图片、OCR、表格和正文共同残留另一方公司、权利人、产品别名或文件路径。

## 排除与降级

- 公共登记模板、标准证书名称、来源明确的公开字段和低证据短语降级。
- 图片模糊、OCR 置信度低、公开来源快照不完整、双方位置或权利人不清时标记 unknown。
- 证据不足时不得断言资质造假、侵犯知识产权或违法，不得把外部搜索摘要当作正式证据。

## 输出要求

- 引用双方表格/合同/证书/图片位置、关键编号和逻辑差异、匹配通道、相似度与证据强度。
- 对 public/tender 合理来源提供真实 source_reference_id；否则明确标记 unknown 并建议人工查验原件。
- verdict 只能为 reasonable、suspicious 或 unknown；不得作出确定性的违法结论。
