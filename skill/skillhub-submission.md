## 三、图文介绍长文案

**标捷通·AI标书检查与查重**——把投标前的最后一道把关交给 AI。

**能做什么**

1. **标书审查**：上传招标文件 + 投标文件，AI 逐项核对响应情况，输出分级问题清单（高风险/待复核/提示），每条带招标依据、投标证据和修改建议，附可下载的审查报告。
2. **标书查重**：上传两份投标文件，分析文本/结构/图片多通道相似度，输出判定结论（reasonable/suspicious）、相似度分数与证据摘录，用于提交前自查雷同风险。

**怎么用**

安装后只需三步：注册标捷通账号并获取 API Key（check.aibjt.com:30002 个人中心 → API Key（Skill 接入））→ 把 Key 粘贴到对话 → 给出文件路径并说需求（"帮我审查这份标书" / "查一下这两份像不像"）。全程自然语言，命令由助手代跑。

**说明**

- 任务在云端异步执行，单个任务通常数十分钟，期间可做其他事，支持断点续查。
- 按点计费（任务完成后按实际用量结算），需标捷通账号；详见技能内计费说明。
- 文件经 https 上传至标捷通云端处理，支持 pdf/docx/doc/xlsx，单份最大 1GiB。
