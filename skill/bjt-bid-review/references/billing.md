# 计费口径（必须向用户如实转述）

## 三句话口径

1. **按点计费，任务完成后结算**：任务结束按实际 AI 用量折算扣点（1 元 = 10 点 × 功能倍率），发起时只校验余额 > 0，不预冻结。
2. **失败或取消的任务也可能产生费用**：AI 处理成本已发生即计入结算（与 Web 端同一口径）。这是与「只有成功才收费」类产品的关键差异，提交前必须让用户知晓。
3. **任务串行**：每个账号同时只能有 1 个未结算任务；第二个任务须等前一个终态（409 `active_task_exists`）。

## 提交前确认清单（助手必须逐项完成）

- [ ] `me` 查询并告知剩余点数（充值点/赠送点分列）
- [ ] 告知本次功能类型（审查/查重）与预计时长（数十分钟）
- [ ] 明示「失败/取消也可能计费」
- [ ] 用户明确同意后才执行提交命令

## 余额不足（402）

引导用户到 https://check.aibjt.com:30002 「个人中心 → 订单与消费」充值或领取赠送点数，到账后重试。不要把 API Key 拼进任何 URL。

## 费用明细

- 用户可在标捷通平台 https://check.aibjt.com:30002 「个人中心 → 订单与消费」查看点数流水（充值/赠送/消费分列，消费带任务号）。
- 对账疑问：保留 task_id 联系客服（check.aibjt.com:30002 平台客服）。

## 查重的责任边界（转述给用户）

查重结果仅供**提交前内部自查**参考，不构成围标、串标或违法违规的法律认定；请用户确认其合法持有并有权处理所上传的全部文件。
