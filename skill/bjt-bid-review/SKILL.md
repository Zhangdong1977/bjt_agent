# 标捷通·AI标书检查与查重

> 📌 本文档同时是 AI 助手的执行手册：文末「🚫 对用户输出的铁律」优先级最高、覆盖全文；一切命令由助手后台代跑（操作细节见 [references/usage.md](references/usage.md)），接口契约见 [references/api.md](references/api.md)，计费口径见 [references/billing.md](references/billing.md)。

## 快速开始：获取 API Key

用本 skill 做标书审查/查重，只需一个标捷通 API Key：

1. 打开 https://check.aibjt.com:30002 （标捷通·AI标书检查平台），注册并登录（即标捷通账号）；
2. 进入「**个人中心 → API Key（Skill 接入）**」页签，点击**生成新 Key**，在弹窗中**立即复制**完整 Key（形如 `bjt_live_xxxxx`；**只展示这一次**，遗失只能吊销重生成）；
3. 把 Key 直接粘贴到对话里让助手保存（下次免输），例如：「我的 API Key 是 bjt_live_xxxxx，帮我保存一下」。助手收到后代跑保存命令（见 usage.md），不要让用户自己敲命令。

新用户需先在平台完成注册并确保点数余额可用（充值/赠送入口在「个人中心 → 订单与消费」）。无 Key 时各命令会打印上述获取指引而非崩溃。

## 两大功能

### ✅ 标书审查
- **输入**：招标文件 1 份 + 投标文件 1 份（`.pdf` / `.docx` / `.doc` / `.xlsx`，单份 ≤ 1 GiB），本地路径或云端 URL（云端文件先下载到本地再上传）。
- **输出**：分级问题清单（高风险 / 待复核 / 提示，每条带招标依据、投标证据与修改建议）+ 总体结论 + 审查报告（PDF）链接。
- **使用示例**（用户可以这样说）：
  - 「帮我审查这份投标文件 `/Users/me/某项目投标文件.docx`，招标文件是 `/Users/me/某项目招标文件.pdf`」
  - 「投之前帮我看看这份标书有没有废标风险」
  - 「对照招标文件检查一下响应有没有遗漏」
  - 用户得到：「高风险 N · 待复核 M · 提示 K」+ 一句话结论 + 问题清单要点 + 审查报告链接。

### 🔁 标书查重
- **输入**：2 份**不同**的投标文件（格式同上），可备注说明文件来源。
- **输出**：判定结论（reasonable / suspicious / unknown）+ 相似度分数 + 分通道风险（文本/结构/图片）+ 证据摘录（章节、位置、预览）+ 查重报告链接。
- **使用示例**（用户可以这样说）：
  - 「帮我查一下这两份投标文件有没有雷同风险：`/Users/me/A公司投标.docx` 和 `/Users/me/B公司投标.docx`」
  - 「投之前帮我看两份标书像不像，会不会被判围标」
  - 用户得到：判定结论、相似度分数、主要证据摘录与建议 + 报告链接。

## 任务流程（助手代跑，命令见 usage.md）

1. **配置凭证**：用户粘贴 Key → `login` 保存；先 `me` 自检连通与剩余点数。
2. **上传解析**：逐份 `upload`（招标=`tender`，投标=`bid`；查重两份=`duplicate_left`/`duplicate_right`），等解析完成（`documents <id>` 至 `parsed`）。加密/损坏文件会解析失败——先让用户解密导出再传。
3. **计费确认（必须）**：向用户报告剩余点数与计费口径（见 billing.md：任务完成后按实际用量扣点，**失败或取消的任务也可能产生费用**），取得用户**明确同意**后再提交。用户未回应不得提交。
4. **提交任务**：审查 `review`、查重 `duplicate` → 得到 `task_id`。若返回"已有进行中任务"（每账号同时仅 1 个未结算任务），告知用户等待或用 `list` 查看进度，稍后再试。
5. **轮询进度**：命令自动轮询（也可 `status <task_id>` 手动查），通常需数十分钟；期间可让用户先处理其他事务。会话中断后用 `list` 找回 `task_id` 续查，不要重复提交。
6. **交付结果**：把结论、问题清单/证据摘录**总结给用户**，并附报告链接（链接有时效，提醒及时查看/下载）。用户要求中止时 `cancel <task_id>`，并说明取消也可能计费。

## 异常对照

| 现象 | 处理 |
|---|---|
| 401/403 Key 无效 | 引导按「快速开始」到 check.aibjt.com:30002 个人中心重新生成并保存 Key |
| 402 余额不足 | 引导到 check.aibjt.com:30002「个人中心 → 订单与消费」充值后再提交 |
| 409 已有进行中任务 | `list` 查看进度，等完成后再提交，勿重复 |
| 上传格式被拒 | 核对 pdf/docx/doc/xlsx 与单份 ≤1GiB |
| 解析失败 | 多为加密/损坏文件，解密导出后重传 |
| 查重提示两份文件相同 | 让用户确认是否传错文件，更换后重试 |
| 网络错误/超时 | 稍后重试；云端任务不受影响，用 `list`/`status` 续查 |
